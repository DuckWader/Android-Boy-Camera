# GB Pocket Print

`index.html` является исходным файлом веб-проекта и не запускается напрямую
через `file://`, потому что браузер блокирует JavaScript-модули.

Для локального запуска дважды щёлкните файл:

`Открыть GB Pocket Print.cmd`

Страница откроется по адресу <http://localhost:4173>. Окно терминала должно
оставаться открытым до завершения работы.
