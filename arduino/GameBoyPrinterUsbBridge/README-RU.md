# Game Boy Printer USB Bridge

Это отдельная версия скетча, которая работает только как прозрачный переходник:

```text
телефон или компьютер ↔ USB Serial ↔ Arduino ↔ Game Boy Printer
```

Исходный проект `GameBoyPrinterEmulator` не изменён.

## Отличия от оригинального скетча

- Режим эмулятора Game Boy Printer полностью отсутствует.
- Arduino не проверяет наличие принтера при запуске.
- USB Serial сразу запускается на скорости 9600 бод.
- Каждый полученный через USB байт немедленно передаётся принтеру.
- Каждый ответный байт принтера немедленно возвращается через USB.
- Если принтер был выключен при запуске Arduino, переходник продолжает работать.
  После включения принтера следующие команды приложения будут переданы ему без
  перезапуска Arduino.

## Подключение к Arduino Uno/Nano

| Game Boy Link | Назначение | Arduino |
|---|---|---:|
| Pin 2 | Данные от принтера | D4 |
| Pin 3 | Данные к принтеру | D3 |
| Pin 5 | Тактовый сигнал | D2 |
| Pin 6 | Земля | GND |

Pin 1 кабеля Game Boy Link к питанию Arduino не подключается.

## Настройки последовательного порта

```text
9600 бод
8 бит данных
без чётности
1 стоповый бит
без управления потоком
```

## Загрузка

Откройте `GameBoyPrinterUsbBridge.ino` в Arduino IDE, выберите используемую плату
и последовательный порт, затем нажмите «Загрузить».

После прошивки рекомендуется проверять два сценария:

1. Сначала включить принтер, затем подключить Arduino.
2. Сначала подключить Arduino, затем включить принтер.

В обоих случаях переходник остаётся в одном и том же режиме.
